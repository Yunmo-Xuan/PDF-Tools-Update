## ✨ 软件介绍

PDF 工具箱是一款**完全免费、干净无广告**的 Windows 桌面软件。它集成了多项常用 PDF 处理功能，涵盖查看、拆分、合并、页面管理、文字水印、印章签名、压缩、加密、格式转换、批量处理等场景，帮助您轻松应对日常办公、学习与设计中的 PDF 需求。

### 🌟 核心特点

- **功能全面**：一个软件解决几乎所有 PDF 操作，无需在多个工具间切换。
- **全新界面**：基于现代 Web 技术重构的界面，毛玻璃质感、流畅动画、深色模式，观感与操作体验大幅提升。
- **安装便捷**：提供 64 位与 32 位安装包，双击安装即可使用，自动创建桌面快捷方式。
- **安全可靠**：纯本地运行，不主动上传任何文件，保护隐私。
- **主题配色**：内置蓝、绿、紫、橙四种主题色，浅色 / 深色双模式，随心切换。
- **持续更新**：通过 GitHub 自动检查新版本，更新及时。

1. 从下方下载适用于您系统的安装包（**64 位**或 **32 位**）

## 🔄 自动更新机制

软件启动时会自动检查 GitHub 仓库中的 `version.json` 文件，判断是否有新版本。

- 检测到新版本后，会弹窗提示用户，并打开下载页面（百度网盘）。
- 更新检查仅获取版本号和下载链接，不下载任何文件，安全可控。
- `version.json` 由本仓库维护。

## 🛠️ 开发相关

本项目为个人独立开发。v6.0.3 起采用全新架构，界面与逻辑分层设计：

| 层 | 技术 | 用途 |
|----|------|------|
| 界面层 | HTML + CSS + JavaScript + [pywebview](https://pywebview.flowrl.com/) | 现代毛玻璃 UI、动画、主题切换 |
| 后端层 | Python | 业务逻辑、文件处理 |
| 打包 | PyInstaller | 生成 Windows 安装包 |

处理引擎基于以下开源库：

| 库 | 用途 |
|----|------|
| [PyMuPDF](https://pymupdf.readthedocs.io/) | PDF 渲染、编辑、转换 |
| [pypdf](https://pypdf.readthedocs.io/) | PDF 合并、拆分、加密 |
| [pdf2docx](https://dothinking.github.io/pdf2docx/) | PDF 转 Word |
| [pdfplumber](https://github.com/jsvine/pdfplumber) | PDF 表格提取 |
| [python-pptx](https://python-pptx.readthedocs.io/) | PPT 文件生成 |
| [Pillow](https://python-pillow.org/) | 图像处理与文字水印 |

## ❓ 常见问题

**Q：软件是否需要安装？**  
A：v6.0.3 提供安装包版本，双击安装即可。历史版本（v5.x）为绿色免装版，可从网盘中获取。

**Q：应该下载 64 位还是 32 位？**  
A：绝大多数现代电脑都是 64 位，优先选 64 位。如果是较老的电脑，或者不确定，可以选 32 位，兼容性更广。

**Q：处理文件时会上传吗？**  
A：不会，所有操作均在本地完成，您的文件只保存在您指定的位置。

**Q：为什么自动更新没有反应？**  
A：请检查是否联网或者网络是否可访问 GitHub。

**Q：支持 Mac 或 Linux 吗？**  
A：当前版本仅支持 Windows，未来可能适配其他平台。

**Q：软件出错闪退了，怎么办？**  
A：打开软件「设置 → 打开日志目录」，把日志文件发到反馈渠道，我们会尽快排查。
