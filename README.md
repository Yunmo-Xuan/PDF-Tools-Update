## ✨ 软件介绍

PDF Toolkit 是一款**完全免费、干净无广告、源代码公开**的 Windows 桌面软件。它不做云存储、不做会员、不弹广告，也不需要注册账号：打开一个文件，处理完，成品存到你选的位置，文件始终在你这台机器上。

它面向的场景很具体——你手上有一份或一整本书的 PDF，需要动手整理它：删掉封面广告页、把扫描歪的页面转正、合并两章、抽出关键页、盖章或签名、铺防盗水印、压缩体积、加打开密码，或者转成 Word 继续改。扫描件没有文字层，就在这里直接识别成文字、导出 Word / Excel、生成可以搜索的 PDF。以前这些步骤要开四五个软件，或者把文件传到网上换免费额度；现在一个窗口里点完就行。

> **一句话**：凡是「对 PDF 本身动手」的活，先在这里找一遍。

### 🌟 核心特点

- **本地优先**：PDF 的读写、渲染、压缩、转换、文字识别、拍照增强全在本机完成。只有检查更新、拉取使用条款正文、拉取更新日志正文三类请求会联网，且都是对固定仓库地址的只读请求，断网时所有功能照常可用。
- **扫描件事不用求联网**：文字识别引擎与三档模型**全量装在安装包里**，不下载、不上传、不按需取模型。手机拍的照片也能直接选进来处理。
- **一次一事，产物干净**：每个任务只生成一个成品文件，不会在文件夹里堆出 `xxx_rotated`、`xxx_deleted` 之类的中间文件。原文件永远不被改写。
- **页面管理：改很多次，存一次**：转页、删页、抽页、拖拽排序都在内存里完成，只有点「保存为新文件」时才一次性写盘；意外退出后重新打开会问你要不要接上。
- **大文件不算特例**：查看页最多翻到前 5000 页，页面图与缩略图只按当前视口出图，滚远的会交还；卡片定高，顶部按钮和底部工具条始终在手边。
- **页面上的字可以直接选**：查看页在页面图上铺一层按坐标对齐的透明文字，鼠标按住拖过几句就选中，松手即可复制——不是只能整页另存成图片。
- **十种界面语言**：简体中文、繁體中文、English、日本語、한국어、Français、Русский、Deutsch、Español、Italiano，默认跟随系统语言；连软件名本身也按语言显示，安装向导同样是这十种。
- **10 套主题色 + 深色模式**：启动画面、主界面、设置窗口、放大预览共用同一份设置，不会「换了一半」。
- **源代码公开**：以 AGPL-3.0 授权，任何改动版再分发都必须同样开源。你可以读、可以改、可以拿去做你自己的东西。

## 🧩 功能总览

导航按用途分成三组，共**十一个功能页**：核心功能（首页、查看 PDF）、编辑工具（拆分与合并、印章 / 签名、文字水印、内容提取、排版与整理）、高级功能（压缩 PDF、批量处理、安全与整理、格式转换、文档信息）。

| 模块 | 功能描述 | 要点 |
|------|----------|------|
| 📄 **查看 PDF** | 连续滚动翻阅、缩略图导航、缩放与选字 | **拖选页面文字直接复制**；底栏平时收成一颗胶囊标，悬停展开、可固定；两栏单向跟随 |
| 📑 **页面管理** | 提取、删除、旋转、拖拽排序、右键菜单、书签、放大预览 | **改多少次都行，只在点「保存」时写一个文件**；撤销 / 放弃修改 / 未保存改动自动留底 |
| ✂️ **拆分 PDF** | 按每 N 页折，或按你写的页码范围折 | 页码范围支持中文逗号、乱序，越界会明确提示 |
| 📎 **合并 PDF** | 多个文件按你排的顺序合成一份 | 列表可拖拽行首的 ⋮⋮，也可以用 ↑↓ 按钮 |
| 🖊️ **印章 / 签名** | 图片印章或手绘签名，指定页或全部页；还有**骑缝印** | 一枚章按页竖切成条、逐页贴回页缝，写完**逐页重开核对**位置 |
| 💧 **文字水印** | 文字、颜色、不透明度、字号、对角线平铺与密度 | 直接在真实页面上预览，不用「导出后才知道长什么样」 |
| 📑 **内容提取** | 导出 TXT / 图片 / HTML / **LaTeX** / **OCR** | 五个标签；OCR 那格可导出 Word（真表格）与 Excel（一页一张表） |
| 🔧 **排版与整理** | 页面管理、加页码、页眉页脚、裁剪幅面、缩放幅面、**拍照变清晰** | 拍照那格能认纸的四角把梯形拉回矩形、去阴影、纠偏，照片还能一步合成 PDF |
| 📦 **压缩 PDF** | 轻度 / 中度 / 重度三档 | 状态栏写明前后大小 |
| 📁 **批量处理** | 一次挑多个文件，批量拆分 / 转换 / 压缩 | 目标格式含 Word、Excel、PPT、PNG、JPEG、**LaTeX**；某个文件失败不影响其余 |
| 🔒 **安全与整理** | 敏感信息涂黑、清理隐藏信息、权限限制、加密 / 解密 | 涂黑是真的把内容从文件里移除；身份证与手机号带自动校验；检测可以中途停 |
| 🔄 **格式转换** | PDF ↔ Word / Excel / PPT / 图片 / 文本 / **LaTeX** | LaTeX 转 PDF 由**程序自带排版器**完成，不依赖本机是否装了 TeX |
| 🏷️ **文档信息** | 编辑元数据；识别**生成工具链**与**字体情况** | 认得出 pdfTeX / XeTeX / LuaTeX / dvips / xdvipdfmx / TeXShop；字体没内嵌、Type3 位图字这些坑会写明影响 |
| 🖨️ **打印** | 查看页 Ctrl+P，带**打印预览** | 一页一看 / 两面并排 / 整册铺开三种视图，改任何一项，「这一趟会怎么打」立刻重算 |
| ⚙️ **设置** | 基础设置 / 高级设置 / 关于，每页再分小页 | 十色主题、深色、语言、悬停展开、右键菜单、缩略图清晰度、暂存策略、OCR 预加载、日志与诊断 |
| 📜 **最近文件** | 首页展示最近打开的文件 | 最多保留 10 条，常用功能还能**钉在首页最前面** |

**几个可能会被你忽略的细节**

- **长任务随时可以停**：整本识别、导出 Word / Excel、生成可搜索 PDF、扫描质检、自动书签、整本拍照增强、一批照片增强，做的时候右下角写明「第几页 / 共几页」并给一个「取消」。取消不是白做——已经处理完的页照常给出、已经写出的文件照常保留；一页都没做完时不会写出空文件。
- **混合着排的文件会自动分流**：一份 PDF 里既有扫描页、又有本来就带文字层的页，带文字层的那些不再拍成图重认，而是直接抽出原有文字，页号后面标「内嵌文字 / 本次识别 / 沿用上次」。
- **表格按页面上画出来的框线认定**：被横竖框线围成格子的才算表格，导出写成真正的 Word / Excel 表格；正文里「编号 + 词条 + 释义」那种两列排布不会被误判。原文留给学生填写的那一条横线也会保留成下划线。
- **左右两栏按栏读**：报纸、讲义与答案解析这类双栏页面，先把左栏从上到下读完再读右栏，通栏标题在最前、页脚在最后，不会左右串句。
- **认不准就不动**：拍照增强的四角识别、纠偏、裁边三个开关各自判断，认不出纸边就原样交回，不会硬拉出一张花页。
- **算不出来就说算不出来**：取不到的量显示「—」并写明原因；没能照做的命令会在结果里逐条列出哪一行、哪一条，不会出现「提示成功但内容少了」。

## 🚀 快速开始

### 系统要求

- **Windows 10 或 Windows 11（64 位）**。这一版不再提供 32 位包。
- **WebView2 运行时**：Windows 11 自带；Windows 10 通常随 Edge 浏览器已安装。安装包已经把微软官方的完整运行时**一并带上（数字签名原件）**，所以**一台完全没有网络的机器也能一次装成功**；装完还会自动确认组件是否就位，装不上会在安装日志里写明栽在哪一步，而不是留一个打不开的程序。

### 安装

1. 从下方下载 `PDFToolkit-7.0.3-Setup.exe`
2. 双击运行。安装向导本身提供十种语言，默认按你系统的显示语言显示，也可以在向导右上角换一种
3. 默认安装在用户目录（`%LOCALAPPDATA%\Programs\PDF Toolkit`），**不需要管理员权限**；想换盘或换目录可在向导中修改。安装目录是纯英文，避免各类运行库对中文路径的兼容问题
4. 从桌面快捷方式或开始菜单启动

> 💡 覆盖安装（同版本或新版本再装一次）后首次启动只再显示一次使用条款，你之前设好的语言、主题、更新选项等都不会被改动。

### 第一次打开：五步向导

1. **使用条款**：看完并点「同意并继续」。不点同意程序不会进入主界面。
2. **界面语言**：默认已经选中你这台电脑系统的显示语言，直接下一步即可；不在十种之内时用英语。
3. **外观**：挑主题色和深色模式，可「稍后再说」。
4. **更新**：决定是否启动时自动检查新版本。
5. **电脑右键菜单**：出厂是关的。打开后，资源管理器里选中 PDF 文件（可多选）右键就能看到本程序，「打开方式」里也有；它只写当前用户的注册表，**不改 `.pdf` 的默认打开程序**，关掉这一项会把程序自己写过的那几项删干净。

### 第一个任务（五分钟能走完）

打开「排版与整理 → 页面管理」→ 选文件 → 滚一遍，歪页点选后右转、广告页点选后删除 → 点「保存为新文件」。**整个过程只写出一个 PDF，中间不会多出任何文件。**

## 🔄 自动更新机制

软件启动时会自动检查本仓库的 `version.json`，判断是否有新版本。

- 检测到新版本后弹窗提示，正文就是本文件「📝 更新日志」里对应那一版的内容；三个选择：立即下载、稍后再说、查看完整更新日志。
- 更新检查只获取版本号和下载链接，**不下载任何文件**，也不携带你的文件名、路径或任何文档片段。
- 同一组地址还会拉两份纯文本：本仓库的 `LICENSE.md`（使用条款）与 `README.md` 里的更新日志一节，程序内「关于 → 使用条款 / 更新日志」显示的就是它们。
- 这四类请求都同时问多个镜像（几个 jsDelivr 镜像 + GitHub 原始地址），比的是**内容新旧**而不是谁先回答；全部失败时退回随程序内置的副本或本机上次缓存，并如实标明当前看到的是哪一份。所以网络不畅时功能照常用，只是看到的条款可能是上一次的。

> 文件本身（整册扫描件更占资源）、机械硬盘、杀毒软件实时扫描，都会让处理慢一点；这是所有本机工具共同的开销。

## 🔒 你的文件和数据去了哪里

- **PDF 只在本地读写**。程序不会把文件内容发给任何外部服务，也没有「在线压缩 / 在线 OCR」这类入口。
- **原文件永远不被改写**。所有成品都是新文件，位置由你在保存对话框里决定。
- **本机配置**：`%APPDATA%\PDFToolkit\config.json`（主题、界面语言、最近打开列表、向导与条款确认记录等）
- **本机日志**：`%LOCALAPPDATA%\PDFToolkit\logs\`，分三类：运行日志、安装 / 首次运行日志、报错日志。设置里能看到具体位置、大小和文件数，也可以「打开日志目录」直接翻，或「清理日志」（只删运行日志及其旧副本）。
- **本机识别缓存**：`%LOCALAPPDATA%\PDFToolkit\ocr_cache\`，存的是逐页识别出来的文字，为的是同一份文件不必反复重算；里面包含你文档的文字，介意请在不用时删掉这一目录。
- **账号与遥测**：没有。不注册、不上报统计、不需要登录，也不收集地理位置与联系方式。
- **卸载**：只删程序本身；上面几处配置与日志留在用户目录（重装可继续使用）。想彻底清掉，手动删除即可。

**只有三类联网**：启动时检查更新（可在向导 / 设置里关掉）、拉取使用条款正文、拉取更新日志正文。翻译功能默认走随包离线词表，**只有你自己指定了翻译服务地址之后**才会向那台服务发文字。

## 🛠️ 开发与源码

本软件源代码以 **AGPL-3.0** 开源（全文见 [`LICENSE`](LICENSE)），授权口径与限制见 [使用条款](LICENSE.md)。界面与逻辑分层：

| 层 | 技术 | 用途 |
|----|------|------|
| 界面层 | HTML + CSS + JavaScript + [pywebview](https://pywebview.flowrl.com/) | 现代 UI、动画、主题切换、十种语言 |
| 后端层 | Python 3.13（64 位） | PDF 处理、文字识别、拍照增强、LaTeX 排版、打印 |
| 打包 | PyInstaller（onedir）+ [Inno Setup](https://jrsoftware.org/isinfo.php) 6.3+ | 生成 Windows 安装包 |

### 仓库结构

```
main.py                程序入口：建窗、启动画面、后台预加载
build.bat              一键构建（含 pyflakes 门禁），产物在 dist\
requirements.txt       运行与打包依赖清单
api/                   暴露给前端的桥接方法，按功能页分文件
core/                  业务逻辑与资源路径、十本语言字典、LaTeX 排版器、坐标换算
assets/                index / settings / splash 三个页面 + js / css / img
                       （其中的 readme.md、license.md 是随包的离线副本）
hooks/                 PyInstaller 收集钩子（paddle 需要按文件系统枚举模块）
installer/             Inno Setup 脚本与版本号生成器
resources/             程序图标（OCR 模型不入库，见下）
```

### 本机跑起来

```bash
# 需要 64 位 Python 3.13
python -m venv .venv-x64
.venv-x64/Scripts/python.exe -m pip install -r requirements.txt
# build.bat 会在缺 venv 时自动建并装依赖；构建统一走 python -m PyInstaller
.venv-x64/Scripts/python.exe main.py          # 直接跑源码
build.bat                                      # 出 dist\PDFToolkit\PDFToolkit.exe
iscc installer\pdf-toolkit.iss                 # 出 dist\PDFToolkit-<版本>-Setup.exe
```

为了让仓库能正常 clone，以下**非源码**内容不在版本管理里，构建正式包时需要自备：

| 缺的东西 | 放在哪 | 怎么来 |
|----------|--------|--------|
| OCR 三档模型 + 韩 / 俄两份识别模型 | `resources\ocr_models\` | 随包的 PP-OCRv6 / PP-OCRv5 模型文件（Apache-2.0，来自 PaddleOCR 官方发布），约 190 MB |
| WebView2 离线完整安装器 | `installer\vendor\` | 微软官方 `MicrosoftEdgeWebView2RuntimeInstallerX64.exe`（约 205 MB，数字签名原件），另有在线 bootstrapper 作兜底 |
| 版本号资源 | `installer\version.iss`、`installer\version_info.txt` | 由 `installer\make_version_info.py` 从 `core\constants.py` 的 `CURRENT_VERSION` 生成，构建时自动重算，不用手改 |
| 真机验收脚本与测试产物 | `tests\` | 本地开发用，不随包；`PDFToolkit.spec` 与 `.iss` 都不会收它 |

**关于依赖版本**：`paddlepaddle==3.3.1`、`paddleocr==3.7.0`、`paddlex==3.7.2` 三者的版本要一起钉住（paddlex 要求 `numpy<2.4` 且钉死 `opencv-contrib-python==4.10.0.84`）。`build.bat` 在装完 requirements 后会再强制重装一次 contrib 版 OpenCV，保证冻结进包的 `cv2` 带 contrib 模块；装包时还会把 `site-packages` 里全部 `*.dist-info` 复制进 `_internal`，否则 PaddleX 通过 `importlib.metadata` 查不到依赖会拒绝启动识别引擎。这两步是实测出来的，别顺手删掉。

## ❓ 常见问题

**Q：文件会被上传吗？**  
A：不会。读取、渲染、压缩、转换、识别全在本机完成。只有检查更新、拉取条款 / 更新日志正文三类联网请求，失败也不影响使用。

**Q：断网了还能用吗？**  
A：能。除了「检查更新」看不到新版本，其余功能全部照常；识别引擎和模型就在包里，安装包里还带了 WebView2 完整运行时，所以连装都能离线装。

**Q：五千页的书会不会卡？**  
A：查看页最多翻到前 5000 页，页面图与缩略图只按当前视口出图、滚远的会交还，所以列表和翻页不随页数变慢。超出的页请用拆分 / 提取按页处理。

**Q：扫描件没有文字层，怎么办？**  
A：用「内容提取 → OCR（Beta）」。可以先「识别文字」看质量，再导出 TXT / Word / Excel，或者「生成可搜索 PDF」让阅读器能搜能复制。要验收扫描质量就用「扫描质检」。

**Q：OCR 出来的结果不准怎么办？**  
A：先确认「识别语言」选对（韩语、俄语要各选对应语言，其余用「自动」）；再用「扫描质检」看有没有模糊、偏暗、倾斜的页，勾上「扫描优化」或重扫；还不理想就把精度换到「均衡」或「精确」。版式乱了看「按位置保留排版」是否勾着。

**Q：手机拍的照片能用吗？**  
A：能。OCR 那格的照片入口可以直接选图片；「排版与整理 → 拍照变清晰」专门处理俯拍的纸面：认出纸的四个角把梯形拉回矩形、去阴影、摆正、裁掉桌面，三档效果，还能把一批照片一步合成一份 PDF。

**Q：我没装 LaTeX，能转 PDF 吗？**  
A：能。「格式转换 → LaTeX 转 PDF」用的是程序自带的子集排版器，不调外部程序、不联网。它不是完整 TeX 发行版：不执行宏包、不做二次编译，认不出的命令会带着内容照常排出来并在结果里逐条写明哪一条没生效。要 Computer Modern 那种一字不差的观感，请用 TeX 发行版。

**Q：改完为什么还要点保存？**  
A：因为「点一下存一个文件」会让你面对一堆中间文件。页面管理里所有改动先攒在内存里，确认整本书都整理好了，再一次性写成成品。没保存时状态栏一直挂着「有未保存的改动」。

**Q：忘了点保存就关了窗口？**  
A：改动会自动留底，重新打开同一份 PDF 会问你要不要接上（策略在设置里可选，默认保留最近 10 份；留的只是页序和旋转，不含页面内容）。

**Q：转成 Word 后版式有点乱？**  
A：文字型 PDF 效果最好；扫描件、复杂跨页表格、艺术字排版属于「本来就难还原」的那一类。只要内容不要版式，可以先转图片或者只复制文字。

**Q：装它要不要管理员权限？**  
A：不要。默认装在你自己的用户目录（`%LOCALAPPDATA%\Programs\PDF Toolkit`）。想装到 `Program Files`，向导里可以改；但安装路径请保持纯英文，运行库对中文路径的兼容不稳。

**Q：这一版为什么改名成 PDF Toolkit？**  
A：安装目录换成了纯英文的 `PDF Toolkit`，避开一部分运行库对中文目录的兼容问题。直接覆盖安装即可，你的设置和日志会自动搬到新程序名下；旧的中文目录会留在原处不再使用，确认新版正常后手动删掉即可。

**Q：换外语后某些地方还是中文？**  
A：PDF 文件里的文字、你自己填的内容、日志，以及「云陌」这类专有署名保持原样；界面文字、按钮、提示、悬浮说明、示例文字都会跟着语言走。真看到没翻的界面文字，请把那处截图发到 Issue。

**Q：我可以商用吗？可以改成我自己的软件吗？**  
A：可以读、可以改、可以用、也可以再分发——条件是分发版必须按 AGPL-3.0 一并公开完整源代码、保留原始版权与许可声明，并且不能冒用「PDF Toolkit」或「云陌」的名义发布。细节见 [使用条款](LICENSE.md) 第一、二条。

**Q：为什么选 AGPL-3.0？**  
A：因为本项目链接的 PyMuPDF 本身就是 AGPL-3.0（或商业授权）双许可——只要把成品分发出去，整体源码就有公开义务。用 AGPL-3.0 是把这个义务正正规规走完，同时它保证任何基于本代码的改动版再分发也必须继续开源。

**Q：为什么安装包有 500 多 MB？**  
A：包里带了文字识别的三档模型、韩语与俄语两份识别模型，以及微软 WebView2 运行时的完整离线安装器（约 205 MB）。换来的是一台完全离线的机器也能装好、装完就能识别——不做「装完再下模型」那种事。
