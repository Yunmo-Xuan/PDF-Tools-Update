## ✨ 软件介绍

PDF 工具箱是一款**完全免费、干净无广告**的 Windows 桌面软件。它不做云存储、不做会员、不弹广告，也不需要注册账号：打开一个文件，处理完，成品存到你选的位置，文件始终在你这台机器上。

它面向的场景很具体——你手上有一份或一整本书的 PDF，需要动手整理它：删掉封面广告页、把扫描歪的页面转正、合并两章、抽出关键页、盖章或签名、铺防盗水印、压缩体积、加打开密码，或者转成 Word 继续改。以前这些步骤要开四五个软件，或者把文件传到网上换免费额度；现在一个窗口里点完就行。

> **一句话**：凡是「对 PDF 本身动手」的活，先在这里找一遍。

### 🌟 核心特点

- **本地优先**：PDF 的读写、渲染、压缩、转换全在本机完成。只有检查更新、拉取许可协议正文、拉取更新日志正文三处会联网，断网时所有功能照常可用。
- **一次一事，产物干净**：每个任务只生成一个成品文件，不会在文件夹里堆出 `xxx_rotated`、`xxx_deleted` 之类的中间文件。
- **页面管理：改很多次，存一次**：转页、删页、抽页、拖拽排序都在内存里完成，只有点「保存为新文件」时才一次性写盘。
- **大文件不算特例**：界面按真实页数列出所有页面，缩略图跟着滚动逐批出现。实测 3000 页整册，翻页与 20 页文件一样顺。
- **8 套主题色 + 深色模式**：蓝、绿、青、蓝绿、紫、粉、红、橙，启动画面、主界面、设置窗口共用同一份设置，不会“换了一半”。
- **持续更新**：通过 GitHub 自动检查新版本，更新及时。

## 🧩 功能总览

| 模块 | 功能描述 | 要点 |
|------|----------|------|
| 📄 **查看 PDF** | 流畅翻阅，缩略图导航，支持缩放 | 整册缩略图分批出图，中文长路径也没问题 |
| 📑 **页面管理** | 提取、删除、旋转、拖拽排序、右键菜单、放大预览 | **改多少次都行，只在点「保存」时写一个文件** |
| ✂️ **拆分 PDF** | 按每 N 页折，或按你写的页码范围折 | 页码范围支持中文逗号、乱序，越界会明确提示 |
| 📎 **合并 PDF** | 多个文件按你排的顺序合成一份 | 列表可拖拽行首的 ⋮⋮，也可以用 ↑↓ 按钮 |
| 🖊️ **印章 / 签名** | 图片印章或手绘签名，指定页或全部页 | **预览里看到的位置，就是成品里的位置** |
| 💧 **文字水印** | 自定义文字、颜色、透明度、字号、密度 | 直接在真实页面上预览，不用“导出后才知道长什么样” |
| 📦 **压缩 PDF** | 轻度 / 中度 / 重度三档 | 对应图片重采样与画质，扫描件收益最明显 |
| 📁 **批量处理** | 一次挑多个文件，批量拆分或批量转换 | 逐个产出，某个文件失败不影响其余 |
| 🔒 **加密 / 解密** | 设置打开密码与权限密码；去掉密码重建时保留文档信息 | 不会因为加密而丢掉标题、作者等元数据 |
| 🔄 **格式转换** | PDF → Word、Excel、PowerPoint、PNG、JPEG | 要接着改文字选 Word（尽量保版式）；PPT 是每页一张图 |
| 🏷️ **文档信息** | 查看并编辑标题、作者、主题、关键词等 | 加密文件需先解密再读，否则界面会误显示“没有元数据” |
| ⚙️ **设置** | 8 套主题色、深色模式、关于、更新日志、许可协议 | 独立小窗口，改完立刻生效，主界面同步换色 |
| 📜 **最近文件** | 首页展示最近打开的文件 | 最多保留 10 条，点一下直接回到那份文件 |

**关于转换**：转 Word 走的是保版式的路线，普通排版的文件效果最好；整册扫描件、跨页表格、艺术字排版本来就难还原，这种情况建议先转图片，或者接受部分错位再手工调整。

## 🚀 快速开始

### 系统要求

- **Windows 10 或 Windows 11（64 位）**。这一版不再提供 32 位包。
- **WebView2 运行时**：Windows 11 自带；Windows 10 通常随 Edge 浏览器已安装。如果缺失，安装器会提示，装完继续即可。

### 安装

1. 从下方下载 `PDF工具箱-6.0.4-Setup.exe`
2. 双击运行，全程中文向导：欢迎 → 选择安装位置 → 准备安装 → 完成
3. 默认安装在用户目录（`%LOCALAPPDATA%\Programs\PDF工具箱`），**不需要管理员权限**；想换盘或换目录可在向导中修改
4. 从桌面快捷方式或开始菜单启动

> 💡 安装包 **82 MB**，装完约占 **256 MB** 磁盘空间。

### 第一次打开：三步向导

1. **使用条款**：看完并点「同意」。不点同意程序不会进入主界面。
2. **外观**：挑主题色和深色模式，可「稍后再说」，之后在设置里改。
3. **更新**：决定是否启动时自动检查新版本，同样可稍后决定。

> 每次覆盖安装都会再问一次条款，这是刻意设计的——装了新版本，就该再看一遍规则。日常使用不会反复打扰。

### 第一个任务（五分钟能走完）

打开「页面管理」→ 选文件 → 滚一遍，歪页点选后右转、广告页点选后删除 → 点「保存为新文件」。**整个过程只写出一个 PDF，中间不会多出任何文件。**

## 🔄 自动更新机制

软件启动时会自动检查 GitHub 仓库中的 `version.json`，判断是否有新版本。

- 检测到新版本后弹窗提示，并打开下载页面（百度网盘）。
- 更新检查仅获取版本号和下载链接，**不下载任何文件**，不携带你的文件名、文件内容或任何文档片段。
- 如果发布侧还没同步版本号，可能会提示“正在使用测试版本”，等发布材料更新后会恢复正常。

## 📊 实测表现（数字，不是形容词）

同一台机器（Windows 10 x64，SSD）实测：

| 场景 | 实测 |
|------|------|
| 打开 1200 页文档 | **0.47 秒**先出清单和第一批图 |
| 第一批 24 张缩略图到场 | **0.6–0.7 秒** |
| 跳到第 1000 页之后 | **1.6–2.1 秒**先画眼前这一屏 |
| 3000 页里乱跳 6 次 | 每次 **0.18–2.64 秒** |
| 改完存一次（1200 页） | **1.75–2.5 秒**，一次写盘、一个成品 |
| 8 页小文件 | **0.74 秒** |

**内存怎么不炸**：缩略图只留住离你最近的那几批，离屏太远的会交出去；滚回远处重新画一次。这样 3000 页和 300 页占的内存几乎一样。

> 文件本身（整册扫描件更占内存）、机械硬盘、杀毒软件实时扫描，都会让这些数字稍慢一点；这是所有本机工具共同的开销。

## 🔒 你的文件和数据去了哪里

- **PDF 只在本地读写**。程序不会把文件内容发给任何外部服务，也没有“在线压缩/OCR”这类入口。
- **原文件永远不被改写**。所有成品都是新文件，位置由你在保存对话框里决定。
- **本机配置**：`%APPDATA%\PDF工具箱\config.json`（主题、最近打开列表、向导版本、条款与日志同步版本）
- **本机日志**：`%LOCALAPPDATA%\PDF工具箱\logs\pdf_toolbox.log`（接口异常与启动里程碑；出问题时可直接把路径给技术支持）
- **账号与遥测**：没有。不注册、不上报统计、不需要登录。
- **卸载**：只删程序本身；上面两份配置与日志留在用户目录（重装可继续使用）。想彻底清掉，手动删除即可。

**只有三处联网**：启动时检查更新（可在向导/设置中关掉）、首次进入或升级后拉取许可协议正文、拉取更新日志正文。全部失败也不影响功能使用。

## 🛠️ 开发相关

本项目为个人独立开发。v6.x 采用界面与逻辑分层架构：

| 层 | 技术 | 用途 |
|----|------|------|
| 界面层 | HTML + CSS + JavaScript + [pywebview](https://pywebview.flowrl.com/) | 现代毛玻璃 UI、动画、主题切换 |
| 后端层 | Python | 业务逻辑、文件处理 |
| 打包 | PyInstaller | 生成 Windows 安装包 |

处理引擎基于以下开源库：

| 库 | 用途 |
|----|------|
| [PyMuPDF](https://pymupdf.readthedocs.io/) | PDF 渲染、编辑、转换 |
| [pypdf](https://pypdf.readthedocs.io/) | PDF 合并、拆分、加密 |
| [pdf2docx](https://dothinking.github.io/pdf2docx/) | PDF 转 Word |
| [pdfplumber](https://github.com/jsvine/pdfplumber) | PDF 表格提取 |
| [python-pptx](https://python-pptx.readthedocs.io/) | PPT 文件生成 |
| [Pillow](https://python-pillow.org/) | 图像处理与文字水印 |

## ❓ 常见问题

**Q：文件会被上传吗？**  
A：不会。读取、渲染、压缩、转换全在本机完成。只有检查更新、拉取条款/更新日志正文三处联网，失败也不影响使用。

**Q：断网了还能用吗？**  
A：能。除了“检查更新”看不到新版本，其余功能全部照常。

**Q：一千页以上的书会不会卡？**  
A：实测跑过 3000 页。列表和翻页不受页数影响，缩略图跟着滚动一批批出现。

**Q：为什么改完还要点保存？**  
A：因为“点一下存一个文件”会让你面对一堆中间文件。现在所有改动先攒在内存里，确认整本书都整理好了，再一次性写成成品。

**Q：忘了点保存就关了窗口？**  
A：改动会丢。没保存时状态栏会一直挂着“有未保存的改动”的提示，看到它就别急着关。

**Q：缩略图看不清上面的字？**  
A：缩略图是为了认版式和图文分布，不是用来读正文的。在那一格上右键选「放大预览」，会用小窗口显示这一页的高清图。

**Q：加密的 PDF 能处理吗？**  
A：先在同软件里用「加密/解密」的解密功能去掉密码，再做后续处理。文档信息页同理——不解密读不到标题作者。

**Q：转成 Word 后版式有点乱？**  
A：文字型 PDF 效果最好；扫描件、复杂跨页表格、艺术字排版属于“本来就难还原”的那一类。如果只要内容不要版式，可以先转图片或者只复制文字。

**Q：装它要不要管理员权限？**  
A：不要。默认装在你自己的用户目录（`%LOCALAPPDATA%\Programs\PDF工具箱`）。想装到 `Program Files`，向导里会给你切换。

**Q：为什么检查更新说我在用测试版本？**  
A：发布侧还没把版本信息同步到新版本号，不是程序坏了。等发布材料更新完，提示会变回正常的“有新版本 / 已是最新”。

## 📌 未来计划

- [ ] 缩略图清晰度可选（64 / 96 / 128 DPI）
- [ ] 双击页面进入高清浏览，支持左右翻页
- [ ] 跨文件批量操作（一次选多本书，批量转页、删空白页）
- [ ] 页面插入：空白页、封面页、从另一份 PDF 抽几页并进来
- [ ] 图片水印（当前只有文字水印）
- [ ] 常用快捷键、拖文件进窗口
- [ ] 暂存改动自动落盘，重启恢复（强杀不丢）

> **这一版已知限制**：缩略图固定 64 DPI（认版式够用，读正文请用放大预览）；放大预览一次一页；暂存改动不落盘；暂无快捷键；需手动选文件（不支持拖拽入窗）；PPT 转换为图片型。
