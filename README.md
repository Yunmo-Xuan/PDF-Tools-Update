## ✨ 软件介绍

PDF 工具箱是一款**完全免费、无需安装、干净无广告**的 Windows 桌面软件。它集成了多项常用 PDF 处理功能，涵盖查看、拆分、合并、页面管理、文字水印、印章签名、压缩、加密、格式转换、批量处理等场景，帮助您轻松应对日常办公、学习与设计中的 PDF 需求。

### 🌟 核心特点

- **功能全面**：一个软件解决几乎所有 PDF 操作，无需在多个工具间切换。
- **绿色免安装**：单文件 EXE，复制即用，不写注册表，不留系统垃圾。
- **安全可靠**：纯本地运行，不主动上传任何文件，保护隐私。
- **多语言界面**：支持简体中文、繁體中文、English、日本語，随时切换。
- **深色模式**：内置浅色 / 深色双主题，护眼且美观。
- **持续更新**：通过 GitHub 自动检查新版本，更新及时。

## 🔄 自动更新机制

软件启动时会自动检查 GitHub 仓库中的 `version.json` 文件，判断是否有新版本。

- 检测到新版本后，会弹窗提示用户，并打开下载页面（百度网盘）。
- 更新检查仅获取版本号和下载链接，不下载任何文件，安全可控。
- `version.json` 由本仓库维护，示例格式如下：

```json
{
  "version": "5.0.3",
  "download_url": "https://pan.baidu.com/s/你的链接"
}
```

## 🛠️ 开发相关

本项目为个人独立开发，使用 **Python + Tkinter** 构建界面，处理引擎基于以下开源库：

| 库 | 用途 |
|----|------|
| [PyMuPDF](https://pymupdf.readthedocs.io/) | PDF 渲染、编辑、转换 |
| [pypdf](https://pypdf.readthedocs.io/) | PDF 合并、拆分、加密 |
| [pdf2docx](https://dothinking.github.io/pdf2docx/) | PDF 转 Word |
| [pdfplumber](https://github.com/jsvine/pdfplumber) | PDF 表格提取 |
| [python-pptx](https://python-pptx.readthedocs.io/) | PPT 文件生成 |
| [Pillow](https://python-pillow.org/) | 图像处理与文字水印 |

## ❓ 常见问题

**Q：软件是否需要安装？**  
A：不需要，下载后双击即可使用，真正的绿色免安装。

**Q：处理文件时会上传吗？**  
A：不会，所有操作均在本地完成，您的文件只保存在您指定的位置。

**Q：为什么自动更新没有反应？**  
A：请检查网络是否可访问 GitHub，以及仓库中的 `version.json` 是否正确。详细排查可查看 [Issue #1](https://github.com/Yunmo-Xuan/PDF-Tools-Update/issues/1)。

**Q：支持 Mac 或 Linux 吗？**  
A：当前版本仅支持 Windows，未来可能适配其他平台。
